# A16 review — one real export per built-in template family

Spec: `apps/web/test/e2e/a16-templates.spec.ts` (final run on the committed code: **8/8 passed,
533 s**). Each project is created through the API from sample fixtures, its jobs run on the real
worker, and the final MP4 is downloaded, probed, fully decoded (`ffmpeg -v error` must print
nothing), loudness-measured and sampled at every scene (frames and a spectrum image under
`artifacts/e2e/a16/`, `summary.json`). I reviewed every sampled frame and the spectra; audio was
checked by measurement (EBU R128 loudness, true peak, silence detection) since this environment
has no audio output.

Issues found by this review and fixed before the final run:

- Text with a solid/translucent backing aligned to the slot bottom was shrunk to ~45% by its own
  padding (P6 hook, T7 names looked tiny). Fixed in the compositor (`backing` padding inside the
  measured box); compositor v3.
- Bottom-aligned text that overflowed spilled upward where the fit check could not see it, so it
  was clipped instead of fitted. Fixed (measure the content block); compositor v4.
- T7 character-name cards used the small label role; now a headline (template v3).

Presets outside A16 have their own reviewed exports: P1/P4/P5 (`m3-talking-head`, A18), P2
(`m2-families`), P3 (`m6-collections`, A19).
